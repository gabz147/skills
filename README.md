# skills

Private backup of the Claude Code and Codex CLI skill libraries from the Windows workstation, captured 2026-09-13.

| Folder | Installs to | Count |
|---|---|---|
| `claude/` | `~/.claude/skills/` (Claude Code) | 172 skills |
| `codex/` | `~/.codex/skills/` (Codex CLI) | 179 skills + `claude-port-manifest.json` |

`manifest.json` lists every skill per client and what was excluded.

## Install on another machine

Windows (PowerShell):

```powershell
git clone https://github.com/gabz147/skills.git
cd skills
.\install.ps1            # copies claude/* and codex/* into the user profile
.\install.ps1 -Client claude   # one client only
.\install.ps1 -Force     # overwrite skills that already exist
```

macOS / Linux / WSL:

```bash
git clone https://github.com/gabz147/skills.git
cd skills
./install.sh             # same behaviour; ./install.sh claude|codex, FORCE=1 to overwrite
```

Both scripts copy whole skill directories, skip ones that already exist unless forced, and print a summary. Restart Claude Code / Codex afterwards so the skill list reloads.

## What is not in here

- `codex/claude-plugin-*` mirrors (55 entries) were excluded: they are generated by installing the corresponding Claude plugins (`context-mode`, `ui-ux-pro-max`, `thedotmack`, `plugin-dev`, ...) and regenerate on the destination machine. Install those plugins first if Codex needs them.
- Claude plugins under `~/.claude/plugins/` (superpowers, context-mode, frontend-design, ...) are not skills and are not included; install them through the Claude plugin marketplace.
- `.system` (Codex internal) is excluded.

## Caveats for the installing agent

- Many skills are third-party (gsd-*, hyperframes-*, caveman, humanize, last30days, human-writing, understand-anything, ...) and carry their own licenses; this repo is a private backup, not a redistribution.
- Some skills embed workstation-specific paths (`C:\Users\Tarlu\...`), for example `deploy-vm`, `davinci`, `mercura`, `obsidian-vault`, `handoff`, `gym-training-library`, `personal-gym-goal-coach`, `reference-to-3d`. Adjust those paths after installing on a machine with a different user or layout.
- `obsidian-vault` and `handoff` expect the shared vault at `C:\Users\Tarlu\Documents\Brain` and the controller in `~/.claude/vault-automation/`; the portable version of that system lives in `gabz147/agent-brain`.
- No credentials are stored here; `last30days/scripts/evaluate_search_quality.py` reads its API key from the environment.
