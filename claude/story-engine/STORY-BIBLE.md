# Story bible — continuity & consistency

Long fiction breaks on inconsistency: eye color shifts, a character knows a thing they shouldn't, timelines drift. Keep a `story-bible.md` alongside the manuscript. **Reread it before each chapter; update it after.**

Track what each character *knows at any given point* — dramatic irony and reveals depend on it.

## Templates

### Character

```
## <Name>
- Role: protagonist / love interest / antagonist / ...
- Age / pronouns / appearance (only details that recur)
- Voice: vocabulary, rhythm, verbal tics, what they avoid saying
- Want (external goal) / Need (internal lesson)
- Fear / wound (the backstory driving behavior)
- Flaw (the thing that makes them fail) / strength
- Small habits & specifics (the chipped nail polish, the way they laugh)
- Arc: where they start → where they end
- Knows / doesn't know: (update per chapter)
- Key relationships: <Name> — dynamic + history
```

### Relationship

```
## <A> & <B>
- Dynamic: (rivals, exes, unspoken crush, ...)
- History: what happened before page one
- Tension source: what keeps them apart
- Beat tracker: meet → spark → push-pull → near-miss → reversal → payoff (mark progress)
```

### World / codex

```
## <Place / system / rule>
- Description (sensory anchors a scene can reuse)
- Rules & limits (especially magic/tech — must stay consistent)
- Who knows about it / how it's hidden
```

### Timeline

```
- Day/Chapter index: what happened, who was where, what changed
- Open threads (planted, unpaid): <thread> — planted ch.N, pay off by ch.?
```

### Style sample

Keep 1–2 short passages that nail the target voice. Reread before drafting to match tone, tense, and POV.

## Continuity checklist (per chapter)

- [ ] Names, appearances, ages consistent with the bible
- [ ] Each character only acts on what they actually **know** so far
- [ ] World/magic rules unbroken
- [ ] Timeline coherent (seasons, days elapsed, ages)
- [ ] Planted threads tracked; schedule their payoff
- [ ] Bible updated with new facts, relationship shifts, and what changed
