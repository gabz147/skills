# Sources

This skill was synthesized from open-source LLM fiction tooling and Wattpad's own craft guides (researched June 2026).

## GitHub repos — pipeline & prompt patterns

- [datacrystals/AIStoryWriter](https://github.com/datacrystals/AIStoryWriter) — multi-stage pipeline (initial outline → chapter outline → chapter writing → revision/polish) and a critique loop. Source of the craft directives: don't skip/summarize days, match pacing to scene energy, show-don't-tell, dialogue must fit the situation, chapters must flow into each other, strip author notes/outline headings.
- [danielsobrado/ainovelprompter](https://github.com/danielsobrado/ainovelprompter) — story-bible model (characters, locations, codex/lore, style samples) and an iterative prose-improvement loop with diff preview. Basis for [STORY-BIBLE.md](STORY-BIBLE.md).
- [KazKozDev/NovelGenerator](https://github.com/KazKozDev/NovelGenerator) — tracking multiple character perspectives and what each character knows over time; emotional-arc synchronization. Basis for the "knows/doesn't know" tracking.
- [yingpengma/Awesome-Story-Generation](https://github.com/yingpengma/Awesome-Story-Generation) — survey of LLM story-generation techniques.
- Others reviewed: TheMostlyGreat/mythos, EdwardAThomson/NovelWriter, dylanhogg/gptauthor.

## Wattpad Creators — craft guides

- [How to write an engaging opening](https://creators.wattpad.com/writing-resources/sentence-level-writing/how-to-write-an-engaging-opening/)
- [Mastering the hook in your stories](https://creators.wattpad.com/writing-resources/webnovel-essentials/mastering-the-hook-in-your-stories/)
- [How to write cliffhangers that captivate](https://creators.wattpad.com/writing-resources/story-and-scene-structure/how-to-write-cliffhangers-that-captivate/)
- [Crafting stories from start to finish](https://creators.wattpad.com/writing-resources/planning-a-story/crafting-stories-from-start-to-finish/)
- [Trends, tropes, and tips from Wattpad HQ](https://creators.wattpad.com/blog/trends-tropes-and-tips-from-wattpad-hq/)
- [Writing for Wattpad: crafting stories that captivate](https://www.automateed.com/writing-for-wattpad) — chapter length (1,000–2,000 words), mobile pacing, short sentences/paragraphs.

Key Wattpad takeaways baked into the skill: hook in chapter 1 on the moment of change; inciting incident in the first 10–15%; 1,000–2,000-word mobile chapters; end on a question tied to goal/conflict; GMCS (Goal, Motivation, Conflict, Stakes) at the core; voice + specificity over polish.
